# A Little Something 🪔

A calm, devotional-inspired single-page salary reveal.

## Files
- `index.html`
- `style.css`
- `script.js`

## GitHub Pages
1. Create a new GitHub repository.
2. Upload these 3 files to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide the Pages URL.

No backend is required.

## Customize
In `index.html`, change:
- `For you, with warmth.`
- `My first ₹1,000 · to you.`
- `It's about the first one.`

The displayed date is generated automatically from the visitor's device date.
